    前端学习笔记

    HTML

    HTML 是网页的结构层，用来描述页面内容及其语义。浏览器会根据 HTML 构建 DOM 树，再结合 CSS 和 JavaScript 生成最终页面。

    1. 基础结构

    <!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>页面标题</title>
  </head>
  <body>
    <h1>主标题</h1>
    <p>页面内容</p>
  </body>
</html>

    关键点：

    • <!doctype html>：声明使用 HTML5 标准。
    • html lang="zh-CN"：声明页面语言，有利于无障碍和搜索引擎。
    • meta charset="UTF-8"：设置字符编码。
    • meta viewport：适配移动端视口。
    • title：浏览器标签页标题，也会影响 SEO。

    2. 常用标签

    文本相关：

    <h1>一级标题</h1>
<h2>二级标题</h2>
<p>段落</p>
<strong>重要内容</strong>
<em>强调内容</em>
<span>行内容器</span>
<br />
<hr />

    链接和图片：

    <a href="https://example.com" target="_blank" rel="noopener noreferrer">
  打开链接
</a>

<img src="./avatar.png" alt="用户头像" />

    列表：

    <ul>
  <li>无序列表项</li>
  <li>无序列表项</li>
</ul>

<ol>
  <li>有序列表项</li>
  <li>有序列表项</li>
</ol>

    表格：

    <table>
  <thead>
    <tr>
      <th>姓名</th>
      <th>年龄</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>张三</td>
      <td>18</td>
    </tr>
  </tbody>
</table>

    表单：

    <form action="/login" method="post">
  <label for="username">用户名</label>
  <input id="username" name="username" type="text" required />

  <label for="password">密码</label>
  <input id="password" name="password" type="password" required />

  <button type="submit">登录</button>
</form>

    表单常见控件：

    • input type="text"：文本输入。
    • input type="password"：密码输入。
    • input type="email"：邮箱输入。
    • input type="checkbox"：多选框。
    • input type="radio"：单选框。
    • textarea：多行文本。
    • select 和 option：下拉选择。
    • button type="submit"：提交按钮。

    3. 语义化标签

    语义化 HTML 是指用合适的标签表达内容含义，而不是只用 div 和 span。

    <header>页面头部</header>
<nav>导航</nav>
<main>页面主体</main>
<section>页面区域</section>
<article>独立文章内容</article>
<aside>侧边栏</aside>
<footer>页面底部</footer>

    优点：

    • 结构更清晰，便于维护。
    • 对搜索引擎更友好。
    • 对屏幕阅读器等辅助技术更友好。

    4. 块级元素和行内元素

    块级元素特点：

    • 默认独占一行。
    • 可以设置宽高。
    • 常见标签：div、p、h1 到 h6、ul、li、section。

    行内元素特点：

    • 不会独占一行。
    • 默认宽高由内容决定。
    • 常见标签：span、a、strong、em、label。

    行内块元素：

    • 通过 display: inline-block 设置。
    • 不独占一行，但可以设置宽高。

    5. HTML 属性

    常用全局属性：

    • id：元素唯一标识。
    • class：元素类名，可重复使用。
    • style：行内样式，不推荐大量使用。
    • title：鼠标悬停提示。
    • data-*：自定义数据属性。
    <button class="btn" data-role="delete">删除</button>

    6. 可访问性基础

    可访问性是指页面对不同用户和设备都可用。

    常见实践：

    • 图片必须提供有意义的 alt。
    • 表单控件用 label 关联。
    • 按钮使用 button，不要用 div 模拟。
    • 交互元素需要能通过键盘访问。
    • 保持合理的标题层级。
    <label for="email">邮箱</label>
<input id="email" type="email" />

<button type="button">提交</button>

    7. SEO 基础

    常见优化：

    • 每个页面有唯一、明确的 title。
    • 使用 meta name="description" 描述页面。
    • 合理使用 h1 到 h6。
    • 图片添加 alt。
    • 链接文本要有明确含义。
    <meta name="description" content="前端学习笔记，包含 HTML、CSS、JavaScript 和 React。" />

    CSS

    CSS 是网页的表现层，用来控制页面布局、颜色、字体、间距、动画和响应式效果。

    1. 引入方式

    行内样式：

    <p style="color: red;">红色文字</p>

    内部样式：

    <style>
  p {
    color: red;
  }
</style>

    外部样式：

    <link rel="stylesheet" href="./style.css" />

    实际开发中推荐外部样式，便于维护和复用。

    2. 选择器

    /* 标签选择器 */
p {
  color: #333;
}

/* 类选择器 */
.card {
  border: 1px solid #ddd;
}

/* ID 选择器 */
#app {
  min-height: 100vh;
}

/* 后代选择器 */
.nav a {
  text-decoration: none;
}

/* 子代选择器 */
.list > li {
  margin-bottom: 8px;
}

/* 伪类选择器 */
button:hover {
  background: #222;
}

/* 伪元素选择器 */
p::first-line {
  font-weight: bold;
}

    3. 选择器优先级

    优先级从高到低：

    1. !important
    2. 行内样式
    3. ID 选择器
    4. 类选择器、属性选择器、伪类选择器
    5. 标签选择器、伪元素选择器
    6. 通配符选择器

    建议：

    • 少用 !important。
    • 少用 ID 写样式。
    • 使用清晰的类名组织样式。

    4. 盒模型

    盒模型由四部分组成：

    • content：内容区域。
    • padding：内边距。
    • border：边框。
    • margin：外边距。
    .box {
  width: 200px;
  padding: 16px;
  border: 1px solid #ddd;
  margin: 24px;
}

    默认盒模型：

    box-sizing: content-box;

    推荐全局设置：

    * {
  box-sizing: border-box;
}

    border-box 表示元素最终宽度包含 content、padding 和 border，布局更直观。

    5. 常用单位

    • px：像素，固定单位。
    • %：相对父元素。
    • em：相对当前元素字体大小。
    • rem：相对根元素字体大小。
    • vw：视口宽度的百分比。
    • vh：视口高度的百分比。
    html {
  font-size: 16px;
}

.title {
  font-size: 2rem;
}

    6. display

    .block {
  display: block;
}

.inline {
  display: inline;
}

.inline-block {
  display: inline-block;
}

.hidden {
  display: none;
}

.flex {
  display: flex;
}

.grid {
  display: grid;
}

    常见区别：

    • display: none：元素不显示，也不占位。
    • visibility: hidden：元素不可见，但仍占位。
    • opacity: 0：元素透明，但仍占位，并可能响应事件。

    7. position 定位

    .relative {
  position: relative;
  top: 10px;
}

.absolute {
  position: absolute;
  top: 0;
  right: 0;
}

.fixed {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

.sticky {
  position: sticky;
  top: 0;
}

    常见定位：

    • static：默认定位。
    • relative：相对自身原位置偏移。
    • absolute：相对最近的非 static 祖先元素定位。
    • fixed：相对浏览器视口定位。
    • sticky：滚动到指定位置后固定。

    8. Flex 布局

    Flex 适合一维布局，可以处理横向或纵向排列。

    .container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 16px;
}

    主轴控制：

    .container {
  flex-direction: row;
  justify-content: space-between;
}

    交叉轴控制：

    .container {
  align-items: center;
}

    常用属性：

    • flex-direction：主轴方向。
    • justify-content：主轴对齐。
    • align-items：交叉轴对齐。
    • flex-wrap：是否换行。
    • gap：子元素间距。
    • flex: 1：按比例分配剩余空间。

    9. Grid 布局

    Grid 适合二维布局，可以同时控制行和列。

    .grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

    响应式网格：

    .grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}

    10. 响应式布局

    媒体查询：

    .container {
  width: 1200px;
  margin: 0 auto;
}

@media (max-width: 768px) {
  .container {
    width: 100%;
    padding: 0 16px;
  }
}

    常见实践：

    • 使用 max-width 而不是固定宽度。
    • 图片设置 max-width: 100%。
    • 使用 Flex/Grid 做自适应布局。
    • 移动端优先时，先写小屏样式，再用媒体查询增强大屏。

    12. BFC

    BFC 是块级格式化上下文，是一个独立的渲染区域。常见作用：

    • 清除浮动影响。
    • 防止外边距合并。
    • 限制内部布局不影响外部。

    触发方式：

    .bfc {
  overflow: hidden;
}

    其他方式：

    • display: flow-root
    • display: flex
    • display: grid
    • position: absolute
    • position: fixed

    优点：

    JavaScript

    JavaScript 是网页的行为层，用来处理交互、数据、网络请求和页面逻辑。

    1. 变量声明

    var oldValue = 1;
let count = 0;
const name = "Alice";

    区别：

    • var：函数作用域，可重复声明，有变量提升，不推荐新代码大量使用。
    • let：块级作用域，可重新赋值。
    • const：块级作用域，不可重新赋值。

    推荐：

    • 默认使用 const。
    • 需要重新赋值时使用 let。
    • 避免使用 var。

    2. 数据类型

    基本类型：

    • string
    • number
    • boolean
    • undefined
    • null
    • symbol
    • bigint

    引用类型：

    • object
    • array
    • function
    • date
    • regexp
    typeof "hello"; // "string"
typeof 123; // "number"
typeof true; // "boolean"
typeof undefined; // "undefined"
typeof null; // "object"
Array.isArray([]); // true

    注意：typeof null 返回 "object" 是 JavaScript 的历史遗留问题。

    3. 运算符

    1 + 2;
5 - 3;
2 * 4;
8 / 2;
7 % 3;

    比较：

    推荐使用严格比较：

    逻辑运算：

a && b;
a || b;

    空值合并：

    5. 函数

    函数声明：

    function add(a, b) {
  return a + b;
}

    函数表达式：

    const add = function (a, b) {
  return a + b;
};

    箭头函数：

    默认参数：

    剩余参数：

}

    6. 作用域和闭包

    作用域决定变量的可访问范围。

    function outer() {
  const message = "hello";

  function inner() {
    console.log(message);
  }

  return inner;
}

const fn = outer();
fn(); // "hello"

    闭包：函数可以记住并访问它创建时所在的词法作用域，即使外层函数已经执行完毕。

    常见用途：

    • 保存私有变量。
    • 函数柯里化。
    • 防抖和节流。
    • React Hooks 中的状态和副作用逻辑。

    7. 数组常用方法

    const numbers = [1, 2, 3, 4];

numbers.map((item) => item * 2); // [2, 4, 6, 8]
numbers.filter((item) => item > 2); // [3, 4]
numbers.find((item) => item === 3); // 3
numbers.some((item) => item > 3); // true
numbers.every((item) => item > 0); // true
numbers.reduce((total, item) => total + item, 0); // 10

    会改变原数组的方法：

    • push
    • pop
    • shift
    • unshift
    • splice
    • sort
    • reverse

    不会改变原数组的方法：

    • map
    • filter
    • slice
    • concat
    • find
    • some
    • every

    React 中更新数组时通常要返回新数组，而不是直接修改原数组。

    9. 原型和原型链

    JavaScript 对象可以通过原型继承属性和方法。

    function Person(name) {
  this.name = name;
}

Person.prototype.sayHello = function () {
  console.log(`Hello, ${this.name}`);
};

const person = new Person("Alice");
person.sayHello();

    查找属性时：

    1. 先找对象自身属性。
    2. 找不到就去对象原型上找。
    3. 继续沿着原型链查找。
    4. 最终到 null 停止。

    10. this 指向

    this 的值取决于函数调用方式。

    const user = {
  name: "Alice",
  sayName() {
    console.log(this.name);
  },
};

user.sayName(); // this 指向 user

    常见规则：

    • 普通函数直接调用：非严格模式下指向全局对象，严格模式下为 undefined。
    • 对象方法调用：指向调用该方法的对象。
    • 构造函数调用：指向新创建的实例。
    • call、apply、bind：显式绑定。
    • 箭头函数：没有自己的 this，继承外层作用域的 this。
    function sayName() {
  console.log(this.name);
}

sayName.call({ name: "Alice" });

    15. 防抖和节流

    防抖：事件连续触发时，只在最后一次触发后执行。适合搜索输入。

    function debounce(fn, delay) {
  let timer = null;

  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}

    节流：一段时间内最多执行一次。适合滚动、拖拽、窗口 resize。

    function throttle(fn, delay) {
  let lastTime = 0;

  return function (...args) {
    const now = Date.now();

    if (now - lastTime >= delay) {
      lastTime = now;
      fn.apply(this, args);
    }
  };
}

    React

    React 是用于构建用户界面的 JavaScript 库。它通过组件化、声明式渲染和状态驱动视图来组织复杂界面。

    常见目录：

  App.jsx
  main.jsx
  components/

    2. JSX

    3. 组件

    函数组件：

    function Button() {
  return <button type="button">点击</button>;
}

    组件复用：

    function UserCard({ name, age }) {
  return (
    <section>

      <p>{age} 岁</p>
    </section>

function App() {
  return <UserCard name="Alice" age={18} />;

    组件命名：

    • 组件名必须以大写字母开头。
    • 文件名通常和组件名一致。
    • 一个组件只负责一类明确职责。

    4. Props

    Props 是父组件传给子组件的数据。

    function Welcome(props) {
  return <h1>你好，{props.name}</h1>;
}

function App() {
  return <Welcome name="Alice" />;
}

    解构写法：

    function Welcome({ name }) {
  return <h1>你好，{name}</h1>;
}

    Props 特点：

    • 从父组件流向子组件。
    • 子组件不应该直接修改 props。
    • props 可以是字符串、数字、布尔值、数组、对象、函数或 React 节点。

    5. State

    State 是组件内部状态，状态变化会触发组件重新渲染。

    import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>{count}</p>
      <button type="button" onClick={() => setCount(count + 1)}>
        +1
      </button>
    </div>
  );
}

    基于旧状态更新：

    setCount((prevCount) => prevCount + 1);

    对象状态更新：

    const [user, setUser] = useState({ name: "Alice", age: 18 });

setUser((prevUser) => ({
  ...prevUser,
  age: 19,
}));

    数组状态更新：

    const [list, setList] = useState([]);

setList((prevList) => [...prevList, newItem]);
setList((prevList) => prevList.filter((item) => item.id !== id));

    6. 条件渲染

    function UserInfo({ user }) {
  if (!user) {
    return <p>请先登录</p>;
  }

  return <p>欢迎，{user.name}</p>;
}

    三元表达式：

    {isLogin ? <UserPanel /> : <LoginButton />}

    逻辑与：

    {message && <p>{message}</p>}

    7. 列表渲染

    function TodoList({ todos }) {
  return (
    <ul>

        <li key={todo.id}>{todo.title}</li>
      ))}
    </ul>

}

    key 的作用：

    • 帮助 React 识别列表项。
    • 提高更新效率。

    建议：

    • 不推荐使用数组索引作为 key，除非列表完全静态。

    9. 表单处理

    受控组件：表单值由 React state 控制。

    import { useState } from "react";

function LoginForm() {
  const [form, setForm] = useState({
    username: "",
    password: "",
  });

  function handleChange(event) {
    const { name, value } = event.target;

    setForm((prevForm) => ({
      ...prevForm,
      [name]: value,
    }));
  }

  function handleSubmit(event) {
    event.preventDefault();
    console.log(form);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        name="username"
        value={form.username}
        onChange={handleChange}
      />
      <input
        name="password"
        type="password"
        value={form.password}
        onChange={handleChange}
      />
      <button type="submit">登录</button>
    </form>
  );
}

    10. useEffect

    useEffect 用于处理副作用，例如请求数据、订阅事件、操作 DOM、定时器等。

    import { useEffect, useState } from "react";

function UserList() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    async function fetchUsers() {
      const response = await fetch("/api/users");
      const data = await response.json();
      setUsers(data);
    }

    fetchUsers();
  }, []);

  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}

    依赖数组：

    • 不写依赖数组：每次渲染后执行。
    • []：组件挂载后执行一次。
    • [value]：value 变化后执行。

    清理副作用：

    useEffect(() => {
  const timer = setInterval(() => {
    console.log("tick");
  }, 1000);

  return () => {
    clearInterval(timer);
  };
}, []);

    11. useRef

    useRef 可以保存一个可变值，修改它不会触发重新渲染。也常用于访问 DOM。

function SearchInput() {
  const inputRef = useRef(null);

  function focusInput() {
    inputRef.current.focus();
  }

  return (
    <div>
      <input ref={inputRef} />
      <button type="button" onClick={focusInput}>
        聚焦
      </button>
    </div>
  );
}

    保存定时器：

    const timerRef = useRef(null);

timerRef.current = setTimeout(() => {
  console.log("done");
}, 1000);

    12. useMemo 和 useCallback

    useMemo 缓存计算结果：

    const total = useMemo(() => {
  return list.reduce((sum, item) => sum + item.price, 0);
}, [list]);

    useCallback 缓存函数引用：

    const handleClick = useCallback(() => {
  setCount((prevCount) => prevCount + 1);
}, []);

    使用建议：

    • 不要为了使用而使用。
    • 当计算成本较高，或函数需要作为依赖传给子组件时再考虑。
    • 先保证代码正确，再考虑性能优化。

    13. 自定义 Hook

    自定义 Hook 用于复用状态逻辑，名称必须以 use 开头。

    import { useEffect, useState } from "react";

function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    let ignore = false;

    async function request() {
      try {
        setLoading(true);
        const response = await fetch(url);

        if (!response.ok) {
          throw new Error("请求失败");
        }

        const result = await response.json();

        if (!ignore) {
          setData(result);
        }
      } catch (requestError) {
        if (!ignore) {
          setError(requestError);
        }
      } finally {
        if (!ignore) {
          setLoading(false);
        }
      }
    }

    request();

    return () => {
      ignore = true;
    };
  }, [url]);

  return { data, loading, error };
}

    使用：

    function UserPage() {
  const { data, loading, error } = useFetch("/api/users");

  if (loading) return <p>加载中</p>;
  if (error) return <p>加载失败</p>;

  return <pre>{JSON.stringify(data, null, 2)}</pre>;
}

    15. Context 使用建议

    适合：

    • 当前用户信息。
    • 主题。
    • 语言。
    • 全局配置。

    不适合：

    • 所有业务状态都放入 Context。
    • 高频变化的大型状态直接放入 Context，可能引起不必要渲染。

    17. 状态管理思路

    状态应该放在哪里：

    • 只有一个组件用：放在当前组件。
    • 多个兄弟组件用：提升到共同父组件。
    • 多层组件共享：考虑 Context。
    • 大型应用复杂共享状态：考虑 Zustand、Redux Toolkit、Jotai 等状态库。

    判断状态是否必要：

    • 能从 props 计算出来的，不一定要存 state。
    • 不参与渲染的值，可以用 useRef。
    • 服务端数据可以交给 React Query、SWR 等请求缓存库管理。

    18. 性能优化

    常见方向：

    • 使用稳定的 key。
    • 避免不必要的 state。
    • 拆分组件，缩小重渲染范围。
    • 对昂贵计算使用 useMemo。
    • 对传给子组件的回调使用 useCallback。
    • 大列表使用虚拟列表。
    • 路由页面使用懒加载。

    懒加载：

    import { lazy, Suspense } from "react";

const About = lazy(() => import("./pages/About"));

function App() {
  return (
    <Suspense fallback={<p>加载中</p>}>
      <About />
    </Suspense>
  );
}

    在条件中调用 Hook：

  const [value, setValue] = useState("");

    忘记清理副作用：

    20. React 组件设计原则

    • 组件职责单一。
    • Props 命名清晰。
    • 状态尽量靠近使用它的地方。
    • 派生数据优先计算，不轻易存入 state。
    • 副作用放在 useEffect 或事件处理函数中。
    • UI 组件和业务逻辑适当分离。
    • 复用逻辑优先考虑自定义 Hook。
